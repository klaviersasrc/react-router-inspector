Why you need it

Three blind spots, gone.

React Router v7 framework mode is fast because it's clever about data — and that cleverness is exactly what makes it hard to debug with the tools you have.

01

Encoded loader data

Single-fetch responses are turbo-stream, not JSON — so the Network tab shows you an unreadable blob. The Inspector decodes it, keeping real types: Dates, Maps, BigInts, undefined.

before: "Unable to decode response"
02

Server-side API calls

Your loaders fetch on the server during SSR. The browser never sends those requests, so no browser tool can show them. The Inspector surfaces each one — URL, headers, body, timing.

before: invisible to DevTools
03

Server logs in a far-off terminal

Loader logs and SSR errors print to the Node process, not the browser console. The Inspector streams them into the same panel — grouped, filterable, next to the browser logs.

How it works

Reads what's real — never reconstructs it.

Other React Router devtools inject an overlay into your app and rebuild a fake network view. This is a real DevTools panel reading real records, from three sources.

Live router bridge

Subscribes to the running data router and reads loader/action state directly — already decoded, real JS objects. No parsing, no guesswork.

Network decode

Captures the browser's .data and API traffic from the DevTools network feed and decodes turbo-stream with the same library React Router uses.

Server bridge

A tiny dev-only Vite plugin streams server stdout and intercepts server-side fetch, surfacing the SSR side the browser physically can't see.

page  →  injected bridge (reads router · patches fetch/console)  →  content script  →  background  →  DevTools panel   ·   dev server  →  Vite plugin (SSE)  →  panel

Quick start

Two minutes to first insight.

Load the extension

Unzip it, open chrome://extensions, turn on Developer mode, and Load unpacked.

Open the panel

On any React Router app, open DevTools and pick the React Router tab. Reopen DevTools if it isn't listed yet.

Add the Vite plugin (optional)

Get it from the panel's ⚙ Server setup — Download or Copy — then add rrInspector() to your dev vite.config. The server logs and ssr calls light up.

Navigate, and watch

Change a filter, submit a form — every load, call, and log streams in, decoded and organized.
