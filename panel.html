    Capture server logs & SSR calls

    The panel already shows everything browser-side. To also see your server logs and SSR fetches, add this dev-only Vite plugin to your app — it streams the server side into this panel. It only runs in dev.

    1. Save the plugin into your project (e.g. tools/vite-plugin-rr-inspector.mjs) — Download below, or Copy the code.
    2. Add it to your vite.config, before reactRouter(): 
      import rrInspector from './tools/vite-plugin-rr-inspector.mjs';

export default defineConfig({
  plugins: [ rrInspector(), reactRouter() ],
});
    3. Restart the dev server. Server logs (tagged server) and ssr rows appear automatically.
